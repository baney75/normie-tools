# Security

NT runs entirely in the person's browser. It has no server, no accounts and no database, and nothing a person types is sent anywhere. The most important security property is that this stays true.

## Report a problem

Please report security problems privately through GitHub: open the [Security tab](https://github.com/baney75/normie-tools/security) and choose **Report a vulnerability**. Do not open a public issue for a security problem.

Useful reports include:

- Anything that sends what a person types off their device, or loads code or files from another server
- Anything that lets one page read another site's data, or lets another site read NT's saved numbers
- A wrong answer in a money tool that a person could act on

We aim to reply within a week. Fixes ship as soon as they pass the repo checks.

## Supported versions

Only the live site at [dbaney.com/nt](https://dbaney.com/nt/) and the `main` branch are supported.
