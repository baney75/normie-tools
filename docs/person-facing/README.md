# Words for people

This folder will hold the words that people read on NT. That means the home page, the tool pages, and the help text.

Everything here is for everyday readers. They have no tech background.

## How we write

- Use short words.
- Say one thing in each sentence.
- Keep each part short.
- Say what will happen before it happens.

## What gets checked

Each file here is checked for plain words, reading level, and length. The checks run on every change.

Notes for builders live in other folders. Those notes are not checked this way.
